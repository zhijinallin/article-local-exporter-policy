# 文章本地导出器隐私政策

最后更新：2026 年 10 月 5 日

本政策适用于 Chrome 扩展“文章本地导出器”。它在你主动操作时，将当前打开且可正常阅读的微信公众号或今日头条文章保存为本地文件；对支持的今日头条视频页，仅保存页面资料卡，不下载视频文件或生成转录。

## 处理哪些信息、用于什么目的

点击扩展后，它会读取当前标签页的网址及本次要导出的页面内容，例如标题、作者或来源、发布时间、正文、链接和图片地址。视频资料卡可能包含页面提供的封面、时长等信息。这些信息只用于识别页面、生成你选择的 HTML、Markdown 或 ZIP 文件，或复制 Markdown 到剪贴板。

扩展不要求注册账号，不读取完整浏览历史、密码或 Cookie，也不会在后台持续读取其他标签页。它不会绕过登录、付费、验证码或其他访问限制。

## 图片请求和对外传输

如果你选择离线 HTML 或 Markdown 图片包，且页面包含需要另行获取的图片，扩展会先请求相应图片域名的可选权限。当前可能请求的域名仅限 `mmbiz.qpic.cn`、`mmbiz.qlogo.cn` 和 `*.toutiaoimg.com`。得到 Chrome 授权后，扩展才会向文章所引用的图片地址发起请求，把可获取的图片放进本机生成的文件。请求不会主动附带 Cookie 或来源页，但图片服务方仍可能按其自身规则处理网络请求。

单个 Markdown 文件和“复制 Markdown”不会下载图片，而是保留原网页的图片网络地址；将来打开或分享这些内容时，阅读软件可能再次访问原图片服务。网络地址可能含有会过期的参数，分享文件前请自行检查。

扩展没有开发者内容服务器，不会把文章正文、图片、导出记录或你使用扩展的行为上传给开发者；不出售数据，也不用于广告、信用评估或与本地导出无关的目的。我们对通过 Chrome 扩展 API 获得的信息的使用遵守 Chrome 应用商店用户数据政策中的有限使用要求。

## 保存、删除与选择

生成的文件由 Chrome 下载到你选择或浏览器设置的本机位置；复制的文本进入你的剪贴板。扩展不另建长期保存文章的数据库，也不提供云同步。你可以自行删除下载文件或剪贴板内容；Chrome 的下载记录和缓存由浏览器管理。

图片域名权限由 Chrome 保存，你可在 Chrome 的扩展程序设置中撤销。拒绝图片权限后，你仍可选择图片使用网络地址的普通 Markdown；不支持离线图片的文件不会被标成完整离线归档。

## 联系与更新

如有隐私相关疑问，可在[本政策仓库的 Issues](https://github.com/zhijinallin/article-local-exporter-policy/issues)中提出。Issues 是公开页面，请勿贴出私人文章正文、下载文件、账号信息或其他敏感内容。

如果扩展的数据处理方式发生变化，本政策会相应更新，并在需要时通过扩展界面或商店资料说明。
